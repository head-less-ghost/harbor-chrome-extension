Harbor download helper

Chrome → Harbor download helper for macOS

Filters

Only apply to auto-intercepted downloads. Right-click and popup downloads always go to Harbor.

Minimum file size

Downloads smaller than this stay in Chrome. Set 0 to send everything. If a file's size is unknown, it goes to Harbor.

Never download from these sites

Downloads from, or started on, these sites stay in Chrome. A domain also covers its subdomains.

    Native helper setup

    1. Load this extension in chrome://extensions (Developer mode → Load unpacked).
    2. In Terminal, go to this folder and run: 
      chmod +x install.sh && ./install.sh
    3. Quit the browser completely (Cmd+Q) and reopen it.
    4. Open the Harbor popup and click Test native helper.

    The extension ID is fixed inside the package, so the installer sets up Chrome, Chromium, Brave, Edge, Vivaldi and Arc automatically — whichever of them are installed.

    The helper lives at
    ~/Library/Application Support/HarborChrome/
