Harbor download helper

Chrome → Harbor download helper for macOS

Native helper setup

  1. Load this extension in chrome://extensions (Developer mode → Load unpacked).
  2. Copy the extension ID shown on the card.
  3. In Terminal, go to this folder and run: 
    chmod +x install.sh && ./install.sh
  4. Paste the extension ID when asked.
  5. Quit Chrome completely (Cmd+Q) and reopen it.

The helper lives at
~/Library/Application Support/HarborChrome/

Independent community extension. Not affiliated with the Harbor app.
